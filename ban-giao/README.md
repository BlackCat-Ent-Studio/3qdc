# Tài liệu bàn giao 3Q Đại Chiến

Bản chép từ máy làm việc (`D:\workspace\3qdc`) để lưu cùng code. Bản gốc được cập nhật ở máy làm việc; thư mục này có thể cũ hơn.

- **Đọc trước tiên:** `docs/he-thong-hai-trang-3qdc.md` — hai hệ thống trang (chính thức `3qdc.wanmeivn.com` + tạm `3qdaichien.wanmeivn.com`), cách mỗi trang chạy, cách đăng bài lên từng trang, cách gỡ trang tạm.
- `HANDOFF.md` — nhật ký bàn giao đầy đủ (mục 0 bối cảnh, mục 3 bài học & bẫy, bảng dòng 1–87).
- `docs/journals/` — kinh nghiệm, lỗi thật và cách sửa theo từng đợt.
- Code web trang tạm: repo riêng `BlackCat-Ent-Studio/3qdaichien`.
- `tien-ma-vo-gioi/` — handoff riêng web Tiên Ma Vô Giới (trước: Hoàn Mỹ Thế Giới, id `hoanmythegioi`) + các bước deploy trang tĩnh (`deploy-v3c.md`).
